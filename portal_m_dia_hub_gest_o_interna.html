Como Publicar este Portal no GitHub Pages (Gratuito)

Siga os passos abaixo para ter um link acessível por toda a equipe da mídia de qualquer lugar.

1

Criar o Repositório

  • Acesse github.com e faça login na sua conta.
  • Clique no botão verde "New" para criar um novo repositório.
  • Nomeie o repositório como midia-hub ou escala-midia.
  • Marque a opção Public.
  • Marque a caixa "Add a README file" e clique em Create repository.
2

Enviar o Arquivo HTML

  • Dentro do seu novo repositório, clique em "Add file" -> "Upload files".
  • Salve este código em seu computador com o nome exato index.html.
  • Arraste o arquivo index.html para a área de upload do GitHub.
  • Clique no botão verde "Commit changes" no final da página.
3

Ativar o GitHub Pages

  • Vá na aba "Settings" (Configurações) no menu superior do repositório.
  • No menu lateral esquerdo, clique na opção "Pages".
  • Em "Build and deployment" -> "Branch", altere de None para main (ou master).
  • Clique no botão Save.
4

Acessar seu Link do Portal

Aguarde cerca de 1 a 2 minutos. O GitHub gerará o seu link público gratuitamente:

https://seu-usuario.github.io/nome-do-repositorio/

Pronto! Você pode fixar esse link no grupo de WhatsApp da mídia da igreja para toda a equipe utilizar no celular.
