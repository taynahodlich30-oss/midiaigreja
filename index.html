Guia de Formatos e Resoluções Padrão

Referência rápida para designers e operadores de mídia.

Instagram Feed (1:1 & 4:5)

  • • Quadrado: 1080 x 1080 px
  • • Retrato: 1080 x 1350 px (Recomendado)
  • • Formato: JPG / PNG (sRGB)

Stories & Reels (9:16)

  • • Resolução: 1080 x 1920 px
  • • Margem de Segurança: 250px topo/base
  • • Vídeo: MP4 (H.264), 30/60 fps

Telão & Datashow (16:9)

  • • Resolução: 1920 x 1080 px (Full HD)
  • • Fundo: Cores escuras para contraste
  • • Letras: Mínimo 40pt para boa leitura

Transmissão & Thumbnails

  • • Thumb YouTube: 1280 x 720 px
  • • Bitrate Vídeo: 6000 Kbps (1080p 60fps)
  • • Áudio OBS: AAC 160Kbps / 48kHz
